##### The quote "A foolish consistency is the hobgoblin of little minds" was written by American philosopher Ralph Waldo Emerson in his 1841 essay, Self-Reliance. *Emerson's Philosophy: Human beings must evolve daily. Do not fear societal judgment or change your mind when new evidence contradicts your past beliefs. Sticking to old ways just to appear consistent is a trap.Folklore Origins: In traditional English tales, hobgoblins are helpful, well-meaning house elves who secretly perform night chores for food. However, they will unleash mischievous practical jokes if insulted or ignored.*
##### creating a virtual environment and activating the same using following command 
```sh
python -m venv ..\..\python3 # creating a virtual environmemnt called python3
..\..\python3\Scripts\activate # activating this environment using activate script
pip install jupyter notebook # installing jupyter notebook in virtual environmemnt
python -m pip install --upgrade pip # to upgrade pip to latest version
jupyter notebook . # running jupyter notebook in current directory
```
